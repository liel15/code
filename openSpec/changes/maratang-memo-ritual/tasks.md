## 1. 앱 뼈대와 화면 상태

- [x] 1.1 왼쪽 히스토리 패널, 중앙 메모 입력 영역, 오른쪽 영수증 영역, 메인 장면 영역이 있는 데스크톱 우선 앱 뼈대를 만든다.
- [x] 1.2 시작, 조리, 먹기, 기절, 완료, 상세 화면을 위한 핵심 UI 상태 모델을 구현한다.
- [x] 1.3 메모 제목이 마라탕 주문명이 되어 조리 화면으로 전환되도록 시작 화면을 연결한다.

## 2. 히스토리와 저장

- [x] 2.1 메모 히스토리, 재료 목록, 맵기, 완료 상태를 담는 로컬 저장 데이터 형식을 정의한다.
- [x] 2.2 앱 시작 시 저장된 히스토리를 불러오고, 가능하면 마지막 유효 세션을 복원한다.
- [x] 2.3 히스토리 항목을 선택하면 상세 화면이 열리고 저장된 마라탕 장면과 조리 타임라인이 복원되도록 연결한다.
- [x] 2.4 저장 데이터가 없거나 유효하지 않을 때 안전하게 빈 상태로 돌아가도록 처리한다.

## 3. 조리와 먹기 놀이

- [x] 3.1 조리 시작 시 국물만 있는 빈 냄비를 보여주고, 재료 트레이를 렌더링해 드래그 또는 포인터 기반으로 재료를 냄비에 넣는 동작을 구현한다.
- [x] 3.2 현재 재료와 메모 제목을 기준으로 영수증 항목과 총 가격을 파생해서 보여준다.
- [x] 3.3 조리 중 맵기 선택을 구현하고, 먹기 화면으로 들어갈 때 맵기 값을 유지한다.
- [x] 3.4 먹기 상호작용을 구현해 맵기를 올리고, 오른쪽 맵기 표시기를 갱신하며, 완성된 마라탕이 중앙에 유지되게 한다.
- [x] 3.5 맵기 100 기절 상태와 10초 잠금, 그리고 자동 복귀를 구현한다.

## 4. 완료, 마무리, 검증

- [x] 4.1 마라탕 완료 동작과 축하 효과, 완료 상태 오버레이를 구현한다.
- [x] 4.2 완료된 세션이 새로고침 후에도 히스토리에서 남아 있도록 저장 경로를 연결한다.
- [x] 4.3 시작 화면은 비워 두고, 조리/먹기 화면은 읽기 쉽게 보이도록 모션, 간격, 강조를 다듬는다.
- [x] 4.4 데스크톱 브라우저에서 드래그, 히스토리 복원, 맵기 상승, 기절 타이밍, 완료 흐름을 검증한다.
