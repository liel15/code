## 왜 필요한가

현재 메모 흐름은 기능적으로는 충분하지만 금방 지나가는 기록에 가깝습니다. 이 변경은 각 메모를 마라탕 조리 경험으로 바꿔서, 입력하고 끝나는 메모가 아니라 다시 꺼내 보고 즐길 수 있는 놀이형 기록으로 만듭니다.

## 무엇이 바뀌는가

- 하나의 메모 입력이 마라탕 장면으로 이어지는 웹 경험을 추가합니다.
- 왼쪽 히스토리 패널을 추가해 이전 메모를 계속 보이고 다시 열 수 있게 합니다.
- 시작, 조리, 먹기, 최대 맵기 기절, 완탕 완료를 위한 상태 화면을 추가합니다.
- 이전 메모의 저장된 상태를 복원하는 마라탕 상세 화면을 추가합니다.
- 재료 드래그, 영수증 갱신, 맵기 변경, 맵기 100 도달 시 10초 기절 같은 놀이 요소를 추가합니다.
- 핵심 동작은 로컬에서 처리하며, 백엔드나 API 계약 변경은 하지 않습니다.
