## 추가 요구사항

### 요구사항: 나무 성장 생명주기
시스템은 전용 탭에 나무를 보여주고, 시간과 돌봄에 따라 씨앗 상태에서 성장 단계로 발전시켜야 한다.

#### 시나리오: 나무가 씨앗으로 시작함
- **WHEN** 사용자가 처음 나무 탭을 열 때
- **THEN** 시스템은 나무를 씨앗 또는 새싹 상태로 표시해야 한다

#### 시나리오: 돌봄으로 성장함
- **WHEN** 나무가 유효한 돌봄을 시간에 따라 받았을 때
- **THEN** 시스템은 나무를 다음 성장 단계로 진행시켜야 한다

### 요구사항: 하루 무료 물주기와 코인 소비
시스템은 하루 최대 3회의 무료 물주기를 허용하고, 추가 물주기는 코인을 소비하는 유료 물주기 아이템으로만 가능해야 한다.

#### 시나리오: 무료 물주기 횟수 제한
- **WHEN** 사용자가 오늘 이미 무료 물주기를 3번 사용했을 때
- **THEN** 시스템은 이후 물주기에 구매한 물주기 아이템을 요구해야 한다

#### 시나리오: 구매한 물은 코인을 사용함
- **WHEN** 사용자가 물주기 아이템을 구매해 나무에 사용했을 때
- **THEN** 시스템은 아이템 가격만큼 코인을 차감하고 물주기 효과를 적용해야 한다

### 요구사항: 과도한 물주기는 피해를 줌
시스템은 안전한 한도를 초과한 물주기에서 나무 체력을 감소시켜야 하며, 체력이 너무 낮아지면 썩음 또는 손상 상태를 보여줘야 한다.

#### 시나리오: 과도한 물주기가 피해를 줌
- **WHEN** 사용자가 안전한 양을 초과해 나무에 물을 주었을 때
- **THEN** 시스템은 성장 대신 체력을 감소시켜야 한다

#### 시나리오: 낮은 체력은 손상 상태를 보여줌
- **WHEN** 나무 체력이 설정된 최소 임계값 아래로 떨어졌을 때
- **THEN** 시스템은 손상되었거나 썩은 상태를 보여줘야 한다

### 요구사항: 치료 아이템은 체력을 회복함
시스템은 약과 수액 같은 치료 아이템을 구매하고 사용해 아픈 나무의 체력을 회복할 수 있게 해야 한다.

#### 시나리오: 치료 아이템이 상태를 개선함
- **WHEN** 사용자가 아픈 나무에 약 또는 수액을 사용했을 때
- **THEN** 시스템은 아이템 효과에 따라 나무 체력을 회복시켜야 한다

#### 시나리오: 치료 아이템은 구매가 필요함
- **WHEN** 사용자가 치료 아이템을 보유하지 않았을 때
- **THEN** 시스템은 코인 구매 후에만 아이템을 사용하게 해야 한다

### 요구사항: 나무 말풍선 반응
시스템은 사용자가 나무를 클릭하면 현재 상태와 애정도에 맞는 말풍선 반응을 보여줘야 한다.

#### 시나리오: 나무가 상호작용에 응답함
- **WHEN** 사용자가 나무를 클릭했을 때
- **THEN** 시스템은 상황에 맞는 말풍선을 표시해야 한다

#### 시나리오: 나무가 목마름을 알림
- **WHEN** 나무 체력이 목마름 임계값 아래로 떨어졌을 때
- **THEN** 시스템은 목말라요 같은 말풍선을 보여줘야 한다

### 요구사항: 나무 꾸미기
시스템은 새 집, 배경 장식, 옷 입히기를 포함한 외형 꾸미기를 지원해야 한다.

#### 시나리오: 장식 아이템을 장착함
- **WHEN** 사용자가 나무용 장식 아이템을 선택했을 때
- **THEN** 시스템은 해당 아이템을 나무 화면에 표시해야 한다

#### 시나리오: 꾸미기 상태가 유지됨
- **WHEN** 사용자가 나중에 다시 나무 탭으로 돌아왔을 때
- **THEN** 시스템은 이전에 선택한 꾸미기 구성을 유지해야 한다

### 요구사항: 성장 완료 후 수확과 시장 판매
시스템은 성장률이 100%가 되면 나무를 수확할 수 있게 해야 하며, 수확 시 나무꾼 연출과 절단 애니메이션을 보여준 뒤 시장 판매로 코인을 보상해야 한다.

#### 시나리오: 성장률 100%에서 수확 가능함
- **WHEN** 나무 성장률이 100%에 도달했을 때
- **THEN** 시스템은 사용자가 나무 수확을 선택할 수 있게 해야 한다

#### 시나리오: 수확 시 나무꾼 애니메이션이 재생됨
- **WHEN** 사용자가 나무 수확을 선택했을 때
- **THEN** 시스템은 나무꾼 등장과 나무를 베는 애니메이션을 재생해야 한다

#### 시나리오: 수확 후 시장에 팔아 코인을 얻음
- **WHEN** 수확 애니메이션이 완료되었을 때
- **THEN** 시스템은 나무를 시장에 판매한 것으로 처리하고 코인을 지급해야 한다

### 요구사항: 일정 마감 초과 패널티
시스템은 사용자의 전체 일정 마감시간을 기준으로 동작해야 하며, 마감시간을 넘길 때마다 나무 HP를 10씩 감소시켜야 한다.

#### 시나리오: 일정 마감 초과 시 HP가 감소함
- **WHEN** 사용자가 전체 일정 마감시간을 넘겼을 때
- **THEN** 시스템은 나무 HP를 10 감소시켜야 한다

#### 시나리오: 나무는 전체 일정 현황을 반영함
- **WHEN** 사용자가 나무 탭을 확인했을 때
- **THEN** 시스템은 개별 일정이 아니라 전체 일정 현황에 따른 나무 상태를 보여줘야 한다

### 요구사항: HP 0일 때 죽음과 무덤 연출
시스템은 나무 HP가 0이 되면 나무를 죽은 상태로 전환하고 뒤 배경에 무덤을 표시한 뒤, 나무꾼이 등장해 일정 준수를 안내하고 퇴장하는 애니메이션을 재생해야 한다.
죽은 나무는 어떤 돌봄이나 상호작용으로도 복구할 수 없어야 한다.

#### 시나리오: HP가 0이 되면 죽음 상태가 됨
- **WHEN** 나무 HP가 0이 되었을 때
- **THEN** 시스템은 나무를 죽은 상태로 전환하고 무덤 배경을 표시해야 한다

#### 시나리오: 무덤이 생기면 나무꾼이 경고함
- **WHEN** 무덤이 표시되었을 때
- **THEN** 시스템은 나무꾼이 등장해 일정 잘 지키라고 말한 뒤 퇴장하는 애니메이션을 재생해야 한다

### 요구사항: 죽은 나무 버리기
시스템은 죽은 나무를 버리는 동작을 제공해야 하며, 사용자가 이를 선택하면 현재 나무를 폐기하고 새 새싹 상태로 다시 시작해야 한다.

#### 시나리오: 죽은 나무를 버리면 새로 시작함
- **WHEN** 사용자가 죽은 나무에서 버리기를 선택했을 때
- **THEN** 시스템은 나무를 새 새싹 상태로 초기화해야 한다

### 요구사항: 번개 버튼과 랜덤 사망
시스템은 번개 버튼을 제공해야 하며, 사용자가 이를 클릭하면 랜덤 확률로 번개가 발생하고 번개가 치면 나무가 타서 죽은 상태가 되어야 한다.

#### 시나리오: 번개 버튼을 눌렀을 때 랜덤 판정이 발생함
- **WHEN** 사용자가 번개 버튼을 클릭했을 때
- **THEN** 시스템은 랜덤 확률로 번개 발생 여부를 판정해야 한다

#### 시나리오: 번개가 치면 나무가 죽음 상태가 됨
- **WHEN** 번개가 발생했을 때
- **THEN** 시스템은 나무를 타버린 죽음 상태로 전환해야 한다

#### 시나리오: 번개 후 무덤과 경고 연출이 이어짐
- **WHEN** 번개로 나무가 죽었을 때
- **THEN** 시스템은 무덤을 표시하고 나무꾼 경고 퇴장 연출을 기존과 동일하게 재생해야 한다

### 요구사항: 홍수 버튼과 배경 소실
시스템은 홍수 버튼을 제공해야 하며, 사용자가 이를 클릭하면 랜덤 확률로 홍수가 발생하고 배경 아이템이 모두 쓸려가며 나무가 죽은 상태가 되어야 한다.

#### 시나리오: 홍수 버튼을 눌렀을 때 랜덤 판정이 발생함
- **WHEN** 사용자가 홍수 버튼을 클릭했을 때
- **THEN** 시스템은 랜덤 확률로 홍수 발생 여부를 판정해야 한다

#### 시나리오: 홍수가 나면 배경 아이템이 사라짐
- **WHEN** 홍수가 발생했을 때
- **THEN** 시스템은 배경 아이템을 모두 제거해야 한다

#### 시나리오: 홍수로 나무가 죽음 상태가 됨
- **WHEN** 홍수로 인해 나무가 피해를 입었을 때
- **THEN** 시스템은 나무를 죽은 상태로 전환해야 한다

#### 시나리오: 홍수 후 무덤과 경고 연출이 이어짐
- **WHEN** 홍수로 나무가 죽었을 때
- **THEN** 시스템은 무덤을 표시하고 나무꾼 경고 퇴장 연출을 기존과 동일하게 재생해야 한다
