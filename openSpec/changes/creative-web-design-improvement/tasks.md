## 1. 시각적 기반

- [x] 1.1 색상, 타이포그래피, 간격, 라운드, 그림자, 모션에 대한 새 시각 토큰을 정의합니다.
- [x] 1.2 새 토큰을 일관되게 재사용할 수 있도록 공통 스타일 프리미티브를 업데이트합니다.

## 2. 페이지 리디자인

- [x] 2.1 더 강한 계층과 더 표현력 있는 섹션 구성을 사용하도록 메인 페이지 구조를 다시 구성합니다.
- [x] 2.2 히어로, 기능, 콘텐츠 섹션을 새로운 창의적 비주얼 언어에 맞게 업데이트합니다.
- [x] 2.3 데스크톱과 모바일에서 레이아웃이 의도적으로 느껴지도록 컴포넌트 간격과 정렬을 다듬습니다.

## 3. 상호작용과 마무리

- [x] 3.1 콘텐츠를 방해하지 않으면서 강조를 돕는 절제된 모션과 전환 상태를 추가합니다.
- [x] 3.2 비필수 애니메이션은 최소화하면서도 reduced-motion 환경에서 사용성을 유지하도록 합니다.

## 4. 검증

- [x] 4.1 주요 브레이크포인트에서 반응형 동작을 확인하고 레이아웃 회귀를 수정합니다.
- [x] 4.2 리디자인된 화면 전반의 대비, 가독성, 시각적 일관성을 검증합니다.
