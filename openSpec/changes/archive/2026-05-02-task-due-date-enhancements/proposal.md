## 왜 필요한가

작업은 제목과 메모만으로는 우선순위를 정하기 어렵고, 완료했을 때의 보상도 부족합니다. 마감일과 보상형 성장 시스템을 함께 넣으면 계획 수립, 긴급도 판단, 지연 작업 확인, 장기적인 동기 부여가 쉬워집니다.

## 무엇이 바뀌는가

- 작업에 마감일 메타데이터를 추가합니다.
- 작업 생성 시 마감일 입력을 요구하고, 이후에는 수정할 수 있게 합니다.
- 작업 목록과 상세 화면에 마감일을 분까지 표시합니다.
- 지연 작업과 임박 작업을 더 명확하게 보여줍니다.
- 마감일 기준 정렬과 필터링을 지원합니다.
- 작업마다 나무를 심고, 완료/지연 상태에 따라 성장 상태를 보여줍니다.
- 완료한 나무를 시장에 판매해 코인을 얻고, 코인으로 장식 아이템을 구매할 수 있게 합니다.

## 기능 범위

### 새 기능
- `task-due-dates`: 작업의 마감일을 설정, 표시, 수정하고 정렬 및 긴급도 판단에 활용합니다.
- `task-tree-rewards`: 작업에 연결된 나무 성장, 판매 보상, 코인 지갑, 장식 아이템 구매를 지원합니다.
