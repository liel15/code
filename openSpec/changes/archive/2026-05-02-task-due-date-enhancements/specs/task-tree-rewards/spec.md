## ADDED Requirements

### Requirement: 각 작업에는 나무가 연결되어야 한다
시스템은 각 작업에 작업용 나무를 연결하고 화면에서 이를 보여줘야 한다.

#### Scenario: 작업 생성 시 나무 표시
- **WHEN** 사용자가 새 작업을 생성할 때
- **THEN** 시스템은 해당 작업에 연결된 나무를 함께 표시해야 한다

#### Scenario: 작업 상세에서 나무 확인
- **WHEN** 사용자가 작업 상세 화면을 열 때
- **THEN** 시스템은 연결된 나무 상태를 보여줘야 한다

### Requirement: 마감일이 지나면 나무는 시들어야 한다
시스템은 작업이 완료되지 않은 상태에서 마감일이 지나면 나무를 시든 상태로 표시해야 한다.

#### Scenario: 마감일 경과 후 미완료 작업
- **WHEN** 작업이 완료되지 않은 상태로 마감일이 지나갈 때
- **THEN** 시스템은 해당 작업의 나무를 시든 상태로 표시해야 한다

### Requirement: 완료한 작업의 나무는 판매될 수 있어야 한다
시스템은 완료한 작업의 나무를 한 번만 판매할 수 있게 하고, 판매 시 코인을 지급해야 한다.

#### Scenario: 완료 작업 판매
- **WHEN** 사용자가 완료한 작업의 나무를 판매할 때
- **THEN** 시스템은 코인을 지급하고 해당 나무를 판매 완료로 표시해야 한다

#### Scenario: 중복 판매 방지
- **WHEN** 사용자가 이미 판매한 나무를 다시 판매하려고 할 때
- **THEN** 시스템은 추가 코인을 지급하지 않아야 한다

### Requirement: 코인으로 장식 아이템을 구매할 수 있어야 한다
시스템은 사용자가 코인을 사용해 나무 장식 아이템을 구매하고 적용할 수 있게 해야 한다.

#### Scenario: 장식 아이템 구매
- **WHEN** 사용자가 코인이 충분한 상태에서 장식 아이템을 구매할 때
- **THEN** 시스템은 코인을 차감하고 아이템을 소유 목록에 추가해야 한다

#### Scenario: 장식 아이템 적용
- **WHEN** 사용자가 소유한 장식 아이템을 나무에 적용할 때
- **THEN** 시스템은 해당 장식을 나무 화면에 반영해야 한다
