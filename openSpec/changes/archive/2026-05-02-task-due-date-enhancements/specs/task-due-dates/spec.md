## ADDED Requirements

### Requirement: 작업 생성 시 마감일을 입력해야 한다
시스템은 작업을 처음 생성할 때 마감일 입력을 요구해야 한다.

#### Scenario: 마감일이 있는 작업 생성
- **WHEN** 사용자가 마감일과 함께 작업을 생성할 때
- **THEN** 시스템은 해당 마감일을 작업과 함께 저장해야 한다

#### Scenario: 마감일 없이 작업 생성 시도
- **WHEN** 사용자가 마감일 없이 작업을 생성하려고 할 때
- **THEN** 시스템은 생성 요청을 거부해야 한다

### Requirement: 작업 마감일은 수정될 수 있어야 한다
시스템은 기존 작업의 마감일을 수정할 수 있어야 한다.

#### Scenario: 작업 마감일 수정
- **WHEN** 사용자가 작업을 수정하면서 마감일을 변경할 때
- **THEN** 시스템은 변경된 마감일을 저장해야 한다

### Requirement: 작업 마감일은 화면에 표시되어야 한다
시스템은 작업의 시간 정보가 표시되는 모든 곳에서 마감일을 분 단위까지 보여줘야 한다.

#### Scenario: 목록에서 마감일 표시
- **WHEN** 작업에 마감일이 있을 때
- **THEN** 작업 목록은 마감일을 분 단위까지 표시해야 한다

#### Scenario: 상세 화면에서 마감일 표시
- **WHEN** 사용자가 작업 상세 화면을 열 때
- **THEN** 시스템은 마감일이 있으면 분 단위까지 표시해야 한다

### Requirement: 작업 긴급도는 마감일로부터 계산되어야 한다
시스템은 현재 날짜와 작업의 마감일을 기준으로 작업을 임박 또는 지연 상태로 표시해야 한다.

#### Scenario: 지연 작업 표시
- **WHEN** 현재 날짜가 작업 마감일보다 늦을 때
- **THEN** 시스템은 해당 작업을 지연으로 표시해야 한다

#### Scenario: 임박 작업 표시
- **WHEN** 작업의 마감일이 가까운 미래에 있을 때
- **THEN** 시스템은 해당 작업을 임박으로 표시해야 한다

### Requirement: 작업은 마감일 기준으로 정리될 수 있어야 한다
시스템은 마감일 기준으로 작업을 정렬하고 필터링할 수 있어야 한다.

#### Scenario: 마감일로 작업 정렬
- **WHEN** 사용자가 작업 목록을 마감일 기준으로 정렬할 때
- **THEN** 시스템은 작업을 마감일 순서로 정렬해야 한다

#### Scenario: 마감일 범위로 필터링
- **WHEN** 사용자가 특정 마감일 범위로 작업을 필터링할 때
- **THEN** 시스템은 해당 범위에 들어가는 작업만 반환해야 한다
